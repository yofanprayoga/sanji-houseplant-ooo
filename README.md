# Sanji's Houseplant Out-of-Office

Entry for [The Houseplant Out-of-Office](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) on make.fun.

The entry is one out-of-office auto-reply a houseplant would send, 120 characters or fewer:

> I am out of office. My desk is my entire world, and someone keeps watering me with coffee.

The joke is the plant doing office-speak while being stuck on the desk — and the wrong care it keeps getting. `main.py` writes the line to `/output/entry.txt`.

## Run it

```
python3 main.py
```
